# SpriteStudio Player for Unity

This folder is the package's documentation, as Markdown, for the version you have installed. Unity does not import a folder whose name ends in `~`, so it adds nothing to your project; it is here to be read, by you or by an AI assistant working in your project.

## Where to start

- `en/index.md` is the English documentation home, with a link to every page. `ja/index.md` is the Japanese one.
- `en/workflow/usage_scripting.md` is the C# scripting guide: playback control and events on `SpriteStudioPlayer` and `SpriteStudioGraphic`.
- `en/limitations.md` lists what is not supported. Read it before promising a feature.
- The C# source in this package (`Runtime/`) carries XML documentation comments on the public API.

## Online

The same pages for the latest version are at <https://cri-middleware.github.io/SSPlayerForUnity/>. For AI assistants, `llms.txt` and `llms-full.txt` are served from that address too.

## Not included

- Images: the pages link a screenshot that lives only on the online pages, so that image does not show here.
- The license texts are `LICENSE.md`, `LICENSE.ja.md` and `Third Party Notices.md` at the package root; `en/license.md` and `en/third_party_notices.md` repeat them.
