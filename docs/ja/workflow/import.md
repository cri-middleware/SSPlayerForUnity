# インポートの自動化

[← ドキュメント目次へ戻る](../index.md)

`.sspj` の変換は、Importer ウィンドウからの手動操作だけでなく、Unity のアセットパイプラインに統合された**自動変換**でも行えます。本ページでは自動化に関する機能をまとめます。

基本的なインポート手順は [アセットのインポートとエディタ連携](./usage_asset_pipeline.md) を参照してください。

## プロジェクト内 `.sspj` の自動変換

プロジェクトの `Assets/` 配下に `.sspj` を配置（またはインポート）すると、`AssetPostprocessor` が検知して自動的に `.ssab` へ変換します。SpriteStudio 側で `.sspj` を更新して再インポートが走るたびに、最新内容へ追従して変換されます。

加えて、次も自動処理されます。

- **テクスチャのインポート設定**: `.sspj` / `.ssab` と同フォルダのテクスチャに、2D アニメーション向けの設定（無圧縮・Clamp・Mipmap 無効など）が自動適用されます。
- **共有マテリアルの自動生成**: `.ssab` が参照するテクスチャに対応する `.mat` が、隣接位置に 1 つだけ自動生成されます。

### 無駄な再変換のスキップ（ダーティチェック）

同一内容（更新日時が同一）の `.sspj` は、エディタセッション内で再変換をスキップします。これにより、無変更の再インポートや、変換完了後の `AssetDatabase.Refresh` による連鎖的な再変換を防ぎます。

## フォルダの一括変換

Importer ウィンドウのドロップ領域に**フォルダ**をドロップすると、その中の `.sspj` を**再帰的に一括変換**します。複数ファイルの同時ドロップにも対応しています。

## 再変換（Reconvert）

すでに変換済みの `.sspj` を変換し直す方法は複数あります。

- **Importer ウィンドウの Recent リスト**: 行をクリックすると再変換。右クリックメニューの **Reconvert** からも実行できます。
- **生成アセットのインスペクタ**: `SpriteStudioAnimeAsset` のインスペクタから元の `.sspj` を再変換できます。

## 出力先の設定

変換結果の出力先は Importer ウィンドウの **Output Folder** で設定します（既定 `Assets/ssab_generated`）。設定は `EditorPrefs` に保存され、エディタ全体で共有されます。

## 注意点

- **`.sspj` はプロジェクト外に置いても構いません**。Importer ウィンドウへドロップすれば、出力先（Output Folder）に変換結果のみが生成されます。元データをリポジトリ外で管理したい場合に便利です。
- **インポート直後の表示が不安定**な場合があります（特に URP）。多くはエディタの再起動で解消します。

## CI/CD 向け: SDK の CLI で変換する

Unity エディタを起動せずにコマンドラインから変換したい場合（CI/CD やビルドパイプラインへの組み込み、大量アセットの一括変換など）は、SpriteStudio7-SDK に同梱されている独立したコマンドラインコンバータを使用できます。エディタ内蔵のインポータが裏で利用している `libssconverter` と同じエンジンです。

> [!NOTE]
> CLI バイナリは **SpriteStudio7-SDK のリリース成果物に同梱**されています。本 Unity パッケージには含まれないため、CLI を利用する場合は SDK 側から別途取得してください。

1. [SpriteStudio7-SDK の Releases](https://github.com/SpriteStudio/SpriteStudio7-SDK/releases) から、該当プラットフォーム（Windows / macOS / Linux）向けの CLI コンバータを取得します。
2. `.sspj` を引数に渡して実行し、`.ssab` を生成します。
3. 生成された `.ssab` を Unity プロジェクトの `Assets/` 配下へ配置すると、`SpriteStudioAnimeAsset` として自動的にインポートされます（隣接テクスチャの設定や共有マテリアルの生成も上記と同様に行われます）。

詳細なオプションや仕様は、SDK リポジトリのドキュメントを参照してください。
