### Rust Runtime Dependencies

`libssruntime` and `libssconverter` are written in Rust and depend on various third-party open-source crates.

**License Location:**
Because the runtime binaries are generated artifacts and not checked into this repository, the corresponding license documents for the Rust dependencies are generated or downloaded during the build/setup process.
You can find these third-party licenses inside the `package/Runtime/Plugins/` and `package/Editor/Plugins/` directories (specifically, `THIRD-PARTY-LICENSES.ssruntime.md`, `THIRD-PARTY-LICENSES.ssconverter.md`, and `LICENSE.md` as generated by the build process) after running the setup scripts.

**Distribution Note:**
If you distribute compiled Unity applications or Unity packages that include `libssruntime`, please ensure you also bundle and distribute the license files (`THIRD-PARTY-LICENSES.ssruntime.md` and `LICENSE.md`) located in `package/Runtime/Plugins/` to comply with the open-source licenses of the underlying Rust crates.
